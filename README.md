*Compliance & GRC — get audit-ready and stay there, self-hosted.*

## Why

DPIAFORGE exists for one job — dpia and eu ai act impact-assessment generator — and does it without a SaaS bill or heavyweight setup.
Single-purpose, scriptable, CI-friendly, self-hostable, and callable by AI agents over MCP.

## Install

```bash
pip install cognis-dpiaforge
# or from this repo:
pip install -e ".[dev]"
```

## Quick start

```bash
dpiaforge --version
dpiaforge scan .                      # scan the current project
dpiaforge scan . --format json
dpiaforge scan . --fail-on high       # non-zero exit for CI gates
dpiaforge mcp                         # expose as an MCP server (Cognis.Studio / Claude Desktop / Cursor)
```
